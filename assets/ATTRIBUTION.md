# Asset sources

`header-dark.svg`, `header-light.svg`, and `starlight-divider.svg` are original, static graphics created for Dakura. The celestial theme uses deep plum (`#171326`), lilac (`#C6B5F4`), rose (`#F0C4DD`), icy teal (`#7DDCE8`), and tiny muted gold accents (`#E2BC86`). The light variant uses pale rose, lilac, and ice backgrounds with darker plum and teal foregrounds for contrast.

The palette and abstract celestial details take inspiration from Citlali's visual aesthetic. The graphics contain no character artwork, copied costume emblems, scripts, remote fonts, or external image references.

The technology logos in `icons/` are unmodified SVGs from [Devicon](https://github.com/devicons/devicon), pinned to revision `6a37858047b0e8d9c9c0e68f4a071fc410652e89` and stored locally to avoid runtime dependencies on an icon service.
